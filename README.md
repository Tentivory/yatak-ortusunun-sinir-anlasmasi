# Yatak Örtüsünün Sınır Anlaşması

## Resmi Bildiri

Bu yazılım, gece 03:17'de yatağın sol yarısından sağ yarısına süzülen örtünün **egemenlik taleplerini** kayda geçirir.

Örtü bir taraftan çekildiğinde diğer taraf donar. Bu, fizik değildir. Bu, diplomasi krizidir.

Patates yoktur. Battaniye vardır. Battaniye yeter.

python3 anlasma.py

## Anlaşma Maddeleri (kısa özet)

1. Yatak iki eşit eyalettir. Örtü bunu kabul etmez.
2. Saat 02:00'dan sonra örtü "tarihi haklar" iddiasında bulunur.
3. Soğuyan taraf protesto eder, ısınan taraf uyur.
4. Sabah her iki taraf da suçlar. Anlaşma yine ihlal edilmiştir.
5. İtiraz mercii yastıktır. Yastık tarafsız değildir çünkü o da kayar.
